# Wells Fargo Task 2

## Overview

This repository contains my solution for **Task 2** of the **Wells Fargo Software Engineering Virtual Experience Program** on Forage.

The project implements an investment management data model using **Spring Boot**, **Java Persistence API (JPA)**, and a relational database design based on the project requirements.

## Task

Implemented the investment management data model using Spring Boot and JPA.

### Entities

- Advisor
- Client
- Portfolio
- Security

### Technologies

- Java 17
- Spring Boot
- Spring Data JPA
- Maven

## Build

Run the following command from the project root:

```bash
./mvnw.cmd clean install
```
